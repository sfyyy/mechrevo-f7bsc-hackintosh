# Support / 支持说明

## English

Support is best-effort and limited to the documented MECHREVO F7BSC reference configuration. Before opening an issue:

1. Read [`README.md`](README.md), [`docs/INSTALL.md`](docs/INSTALL.md) and [`docs/known-issues.md`](docs/known-issues.md).
2. Search existing and closed issues.
3. Confirm the issue reproduces with the documented BIOS version and macOS build.
4. Collect the output of `sudo bash macos/check.sh` with private data removed.
5. State whether recovery was tested and what changed immediately before the failure.

There is no SLA. Unsupported hardware may be closed without troubleshooting. Please do not ask maintainers to provide Apple software, unavailable third-party kexts or SMBIOS identities.

## 简体中文

支持为尽力而为，并仅限文档中记录的机械革命 F7BSC 参考配置。提交 Issue 前：

1. 阅读 [`README.md`](README.md)、[`docs/INSTALL.md`](docs/INSTALL.md) 和 [`docs/known-issues.md`](docs/known-issues.md)。
2. 搜索现有及已关闭 Issue。
3. 确认问题能在文档记录的 BIOS 版本和 macOS build 上复现。
4. 收集 `sudo bash macos/check.sh` 输出并移除隐私信息。
5. 说明是否测试过恢复，以及故障前最后做了哪些改动。

项目没有 SLA。不受支持的硬件可能在不排错的情况下关闭。请不要要求维护者提供 Apple 软件、无法公开分发的第三方 kext 或 SMBIOS 身份。
