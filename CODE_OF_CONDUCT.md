# Code of conduct / 行为准则

This project adopts the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior / 期望行为

- Be respectful and technical. Critique ideas and evidence, not people.
- Assume good faith, but ask for reproducible data when a claim is uncertain.
- Respect privacy: never publish another person's SMBIOS data, logs, credentials or personal information.
- Keep hardware safety warnings explicit. Do not encourage risky steps without recovery guidance.
- Welcome different experience levels and language backgrounds.

- 尊重他人并保持技术讨论，批评方案和证据而不是攻击个人。
- 对不确定结论要求可复现数据，同时默认对方出于善意。
- 尊重隐私：不要公开他人的 SMBIOS 数据、日志、凭据或个人信息。
- 明确标出硬件风险，不要在没有恢复方案时鼓励高风险操作。
- 欢迎不同经验水平和语言背景的贡献者。

## Unacceptable behavior / 不可接受行为

Harassment, discrimination, threats, doxxing, deliberate misinformation, credential or private-data exposure, and encouraging destructive operations without warning are not acceptable.

骚扰、歧视、威胁、人肉、故意传播错误信息、泄露凭据或隐私数据，以及在无警告情况下鼓励破坏性操作，均不可接受。

## Enforcement / 执行

Report conduct issues privately to the maintainer through the contact method listed on their GitHub profile. Reports will be reviewed in good faith. Maintainers may edit or remove content, close discussions, or block participants when necessary.

请通过维护者 GitHub 主页列出的私密联系方式报告行为问题。维护者会善意审查，并在必要时编辑或删除内容、关闭讨论或限制参与者。
